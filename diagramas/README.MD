# Diagramas UML — Proyecto LEAF

Esta carpeta contiene la documentación de modelado del **proyecto LEAF**, organizada en archivos PDF.

Los diagramas utilizan el Lenguaje Unificado de Modelado (UML) para representar la estructura, el comportamiento y las interacciones del sistema.

## ¿Qué son los diagramas UML?

Los diagramas UML son representaciones visuales que permiten describir cómo se organiza un sistema de software, qué funciones realiza y cómo interactúan sus componentes.

## Contenido de la carpeta

La documentación contempla **14 tipos de diagramas UML**, divididos en dos categorías.

### Diagramas estructurales

1. Diagrama de clases.
2. Diagrama de objetos.
3. Diagrama de componentes.
4. Diagrama de despliegue.
5. Diagrama de paquetes.
6. Diagrama de estructura compuesta.
7. Diagrama de perfiles.

### Diagramas de comportamiento

1. Diagrama de casos de uso.
2. Diagrama de actividades.
3. Diagrama de estados.
4. Diagrama de secuencia.
5. Diagrama de comunicación.
6. Diagrama de tiempos.
7. Diagrama global de interacciones.

## Organización de los archivos

Cada archivo PDF corresponde a un tipo de diagrama y presenta una perspectiva específica del sistema LEAF.

El conjunto de diagramas permite comprender las funcionalidades, los procesos internos, las relaciones entre componentes y la arquitectura del sistema.

Este archivo funciona como índice descriptivo de la carpeta para facilitar la consulta de la documentación técnica.
